## 失败、修正与阻塞的真实记录

1. 最初沙箱执行工具测试遇到本机临时目录权限错误，回环样本未能完整写出；改为有权限的本地执行后测试通过。不是应用接口故障。
2. 第一次真实环境验证在服务就绪后遇到新验证器的 `http` 变量遮蔽模块名，提前终止，未执行负载；修正验证器命名。该轮保留FAIL及清理记录。
3. 第二次真实验证的12次读取通过，签到预检因工具错误要求“签到前tasks非空”停止，首次签到负载0次。核对生产实现后确认任务在签到时物化，改按`execution.allowedActions`包含CHECK_IN判断，再验证首次响应与保存状态；没有放宽身份/版本/重放断言，也没有修改业务代码。此轮保留FAIL及清理记录。
4. 修正后完整流程通过；随后对审批元数据输出做字段白名单收紧，在实际仓库运行最终18项测试及独立真实环境，均通过。所有失败/通过轮次分开保存，没有将首轮写成一次通过。
